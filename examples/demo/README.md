# 虚构案例说明

本例模拟“港口预约编码互认试点”引发的媒体讨论。所有事件、国家、媒体、机构、人物、数字和引语均为构造，不改写或匿名化任何具体真实选题。

写法保留正式分析报告的帽段、判断型标题、总领句、分论点和脚注。论述从短期效率转向企业适配、规则参与、平台依赖和透明机制，并在每一层保留来源的条件限制。

原始素材/ 包含六份完整模拟材料，素材整理（按论点）.md 展示整理过程，evidence-map.json 保留论点映射，报告初稿.md 展示成文结果，articles.json 用于 Word 排版。实际媒体目录位于独立配置文件，不用于给虚构案例背书。

运行 `npm run demo` 查看文档输出。该演示不执行实时搜索，不验证真实事实。
