# 分析报告文风规范

本规范保留正式分析报告的结构和论述方法；不绑定任何委托方、固定研究对象或真实案例。用户另有要求时据此调整。所有示范情节见仓库中的虚构案例。

## 一、文体与篇幅

使用正式、克制、紧凑的分析性语言。以媒体、报道、受访者为判断主体，避免第一人称、感叹号和口语表达。完整议题可参考 2000—3000 字；篇幅服从信息量，演示案例可缩短。

## 二、帽段

用 3—5 句交代时间与事件、讨论演变、主要视角和整体特征，以“主要情况如下”收束。帽段不罗列具体媒体，列出的关注维度须与正文一一对应。报道总量必须来自可核查统计；只有收集样本时写“本次整理的样本”，不冒称全网监测量。

## 三、大论点与总领句

每个大论点采用 `（1）**标题**`，下接加粗总领句，再展开分论点。标题回答媒体在作何判断、出现何种叙事模式，避免只写“媒体关注某事”。

总领句可以使用三种结构：张力型（某种收益与某种约束并存）、趋势型（讨论由何处转向何处）、并列型（观察、比较、评估）。选用有证据支撑的一种，不强求对立。

## 四、分论点与论据顺序

以加粗的“一是、二是、三是”判断句起笔，加粗至判断句结束；后接具体媒体、事实、专家意见和脚注。论据可按区域差异、叙事标签、时间演变或“现象—机制—前景”展开，排列方式服务于分析。

默认每个分论点争取至少 3 个独立来源，大论点尽量覆盖多个来源组；数量不足明确说明，不虚构支持度。示例用于演示结构，不要求达到完整研究样本量。

## 五、标签与动态叙事

从多篇材料共有表述或论证方式中提炼简短标签，如效率红利、标准竞逐、条件性合作、规则依赖。分析标签不加引号；直接引述的原文术语可以加引号并标出处。

呈现讨论从技术效果转向规则安排、从短期收益转向长期约束等变化时，必须有时间与文本证据。筹码、议价权、窗口期等词只用于材料实际涉及的策略关系，不能把一般讨论强写成博弈。

## 六、动词与归因

“报道”用于事实转述，“认为”用于受访者判断，“分析称／评论称”用于媒体作者的解释。“声称”用于需要保持距离的未证实说法；“炒作、夸大、刻意、有组织地”等须有对照事实或明确行为证据，不能仅因观点负面使用。

可以分析媒体的论证方式，但不能把作者意图当作已知事实。正反观点均保留原有力度，不按国别预设立场。

## 七、引述与翻译

直引加引号，间接转述不加引号。翻译保留可能性、适用范围、条件、数字与日期，不将“可能”升级为“必然”。专家首次出现采用“机构＋职务＋姓名”，必要时括注原文名；身份未知则不补造。

媒体称谓统一；国别有把握时标明。报刊名可用书名号，通讯社、电视台和网站按通行写法处理。来源所在地与检索分组不应混同。

## 八、脚注与自检

每个独立 URL 一个脚注编号，多次引用复用，按首次出现排序。完整报告可参考 15—25 个脚注，证据与任务要求优先。概括性判断同样需要来源。

检查帽段与正文对应、框架一致、数字与引语准确、限定语完整、归因明确。少用“值得注意的是”“显然”等不能增加信息的过渡语。所有检查与证据缺口记录在 review.md，不混入报告正文。
