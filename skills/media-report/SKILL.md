# Draft the report

Read [writing guidance](references/writing-style.md), the organized evidence, and the task's requested format. Write 报告初稿.md and a separate review.md.

Use the agreed outline. Each analytical claim must be supported by the cited material; distinguish a source's interpretation from the report's synthesis. Do not introduce unprocessed material: organize it first and update the evidence map.

Use `[^N]` citations and URL definitions at the bottom. Assign consecutive IDs by first appearance, reuse IDs for the same URL, and avoid unused definitions. Citation count and report length follow the task, not fixed quotas.

Check numbers, dates, names, quotations, conditions, and claim-to-source correspondence. Verify official statements against original releases when relevant. Where verification is unavailable, retain a clear limitation or omit the unsupported claim.

If the final outline changes, synchronize the evidence map and organized material. Record checks and unresolved issues in review.md; keep process notes out of the report body.
