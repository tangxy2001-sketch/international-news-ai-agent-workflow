# 媒体与地区检索配置

默认配置见 [config/sources.json](../../../config/sources.json)。八组分别为美国、英国、欧洲大陆、日韩、中东、俄罗斯、亚太其他、国际智库。最后一组是来源类型，其余为检索区域；分组不是机构国籍或观点标签。

此表用于查询路由，不是媒体立场数据库，也不保证站点可访问或包含目标日期的内容。跨地区通讯社只放入一组以减少重复查询；报告中的机构国别和身份仍需单独核实。

## 查询构造

把用户提供的研究对象与议题关键词翻译为组内语言。例如 `{研究对象的当地语言名称} {议题关键词} {可选事件词}`。非英语组优先构造当地语言查询，再按需要补充英语查询。不得预置固定国家或研究对象。

每组先用具体关键词和域名约束检索。覆盖不足时，在任务预算内调整关键词、扩展来源，再核实新增来源身份。记录未覆盖区域和语种，不为凑齐分组添加无关内容。

## 元数据

保留 source_group、publisher、source URL 和 published。未知身份或日期标待核验；不能凭顶级域名猜测国别。报告中对媒体观点的判断来自正文，不能从区域配置推导。
